# Restaurant Order System

A Python program where a customer views a menu, orders items
(with quantities), and gets the total bill.

## Features
- Menu stored in a dictionary
- Supports quantities: `3 pizza`
- Supports multiple items in one line: `2 coffee and 3 pasta`
- Keeps asking until the customer is done

## How to run
1. Install Python 3
2. Run: `python restaurant.py`

## Example output
```
Enter your first item you want to order = 2 coffee and 3 pasta
Order of 2 x Coffee has been added.
Order of 3 x Pasta has been added.
Do you want to order anything else? no
The total price to pay is 310
```
